# 셈 (SAM, Stock Audit Mate)

많아서 세기 힘든 재고를 같이 세는 앱입니다. 나사·너트·비즈처럼 작고 많은 부품은 **무게로**, 펼쳐 놓을 수 있는 낱개는 **사진으로**, 쌓아 둔 박스는 **박스 수 × 입수량**으로, 큰 물건은 **직접** 셉니다.

- 혼자, 휴대폰 하나로 씁니다. 가입이 없고, 기록은 **내 휴대폰에만** 저장됩니다.
- 무게로 셀 때는 재고 측정기 **사만다**(ATOMS3 Lite + HX711 + 5kg 로드셀)를 블루투스로 연결합니다.
- 사진 세기는 휴대폰 안에서만 계산합니다(OpenTally 기본 엔진, AI 서버·API 키 없음).
- 엑셀(.xlsx)·CSV·JSON으로 보내고, 백업 파일로 기기를 옮깁니다.

| | |
|---|---|
| 앱 열기 | **https://1dyne.github.io/sam-stock-audit-mate/** → 홈 화면에 추가 |
| 화면 속 캐릭터 | **셈**(삼각 조약돌) — 질문과 안내를 합니다. **사만다**(네모 돌) — 재고 측정기. 화면 속 사만다 눈 색 = 측정기 LED 색 |

## 쓰는 법

1. 앱을 열고 **무엇을 세나요?**에서 내 재고의 생김새를 고릅니다. 셈이 재고마다 세는 방법과 필요한 장치를 먼저 알려 줍니다(정해진 규칙, AI 판단 아님).
2. 자주 쓸 기능만 켭니다: 지난번과 비교 · 최소 수량 알림 · 장부 수량과 비교 · 날짜별로 묶기 · 담기. 언제든 설정에서 바꿉니다.
3. 세는 곳을 만들고 품목 목록을 **공통 목록 쓰기 / 이곳만 따로** 중에 고릅니다. 품목은 엑셀·CSV로 불러오거나 세면서 넣습니다.
4. **세기** → 품목을 고르면 그 품목의 방법으로 바로 시작합니다.

### 무게로 세기

개수 = (올린 무게 − 통 무게) ÷ 개당 무게, 개당 무게 = 샘플 무게 ÷ 샘플 개수

빈 통 올리기 → 10개 올리기 → 전부 올리기. 화면에 **± 몇 개**(오차)가 같이 나오고, 샘플을 늘리면 얼마나 줄어드는지 셈이 알려 줍니다. 개당 무게와 통은 저장해 두었다가 다음에 다시 씁니다.

### 사만다 연결

| 휴대폰 | 방법 | 무게 |
|---|---|---|
| 안드로이드 (크롬) | 앱에서 **사만다 찾기** → `dalgrak-scale-번호` 선택 (블루투스 직접) | 실시간으로 흐름 |
| 아이폰 | 사만다 버튼 **세 번** → 눈이 보라색(키보드 모드) → 아이폰 설정 › 블루투스에서 연결 → 앱에서 **키보드로 연결했어요** | 무게가 멈췄을 때 사만다 버튼을 **한 번** 누르면 그 값이 입력됨 |
| 사만다가 없을 때 | 무게 칸에 다른 저울 숫자를 직접 입력하거나 **연습용 저울**로 흐름을 연습 | |

사만다 버튼: 한 번 = 영점(키보드 모드에서는 무게 입력) · 두 번 = 영점 · 세 번 = 모드 바꾸기 · 길게 3초 = 보정. 자세한 내용은 [`docs/protocol.md`](docs/protocol.md).

## 여러 휴대폰 기록 합치기 (선택)

혼자 쓰면 필요 없습니다. 원하는 사람만 **자기 Cloudflare 계정**(무료 범위)에 서버를 올립니다. 기록이 남의 서버로 가지 않습니다.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/1dyne/sam-stock-audit-mate)

1. 위 버튼 → Cloudflare 로그인 → 배포(데이터베이스 D1과 Durable Object가 자동으로 만들어짐)
2. 셈 앱 › 설정 › **내 서버**에 배포된 주소(`https://sam-stock-audit-mate.<내 계정>.workers.dev`)와 접속 코드(처음 넣는 값이 정해짐)를 넣습니다. 다른 휴대폰도 같은 주소·코드를 넣으면 기록이 합쳐집니다(같은 기록은 마지막에 고친 것이 이김).
3. Wi-Fi 모드 사만다를 쓰면 사만다의 서버 주소를 `https://<서버 주소>/api/v1/readings`, 서버 키를 **접속 코드**로 설정합니다(`SAM_SPEC.md` §4). 앱 설정에 사만다 번호(예: `sam-07`)를 넣으면 아이폰에서도 무게가 실시간으로 흐릅니다.

## 고쳐 쓰기

오픈소스(MIT)라서 저장소를 내 GitHub로 복사(Fork)해 마음대로 고칠 수 있습니다. Claude Code 같은 도구에 이 저장소를 열고 말로 요청하면 됩니다. 앱은 빌드 과정 없이 `web/` 폴더 그대로 동작합니다.

## 개발

```
web/                 앱(PWA, 빌드 없음, 바닐라 ES 모듈)
  js/model.js        세는 규칙과 계산(순수 함수)
  js/db.js           기기 안 저장소(IndexedDB)·백업·동기화
  js/scale.js        사만다 연결: 블루투스·키보드·서버·연습용
  js/views/          화면
  chars/             셈·사만다 그림(뜬 눈·감은 눈)
server/src/index.js  선택 서버(Cloudflare Worker + D1 + Durable Object)
firmware/            사만다 펌웨어 (펌웨어 세션 담당)
tests/               단위 테스트, 끝-끝 테스트
tools/               가짜 Wi-Fi 사만다
```

`npm run e2e`는 Playwright가 필요합니다. 연습용 저울로 처음 시작부터 무게·박스·직접·사진 세기, 엑셀 보내기, 담기, 백업, 아이폰 키보드 모드까지 확인하고 화면을 `dist/e2e/`에 남깁니다. 앱만 띄우려면 `web/`을 아무 정적 서버로 열면 됩니다(블루투스는 https 또는 localhost에서만 동작).
